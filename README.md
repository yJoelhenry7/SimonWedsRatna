# Ratna & Simon — Wedding Website

Church-themed wedding site built with **Vite + React + Framer Motion (`motion`) + Lenis** smooth scroll.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in /dist
```

## Customize

- **All text, date, venues, story, RSVP link:** `src/data.js`
- **Photos:** put them in `public/photos/` as `bride.jpg`, `groom.jpg`, `1.jpg` … `9.jpg`
  (missing photos show a gold monogram placeholder).

## Deploy

Drag the `dist/` folder onto [Netlify Drop](https://app.netlify.com/drop), or import the repo on Vercel.
